# بطاقاتي — Bitaqati

تطبيق بطاقات تعليمية عربي يعمل أولاً دون إنترنت، ويستخدم التكرار المتباعد
لمساعدتك على تذكّر ما تدرسه. تكتب بطاقاتك، وتراجعها في الوقت المناسب،
وتشارك مجموعاتك مع من تريد — أو تنشرها في مكتبة عامة يبنيها الطلاب.

> **الحالة:** التطبيق مكتمل وظيفياً — محرّك مراجعة محلي، مزامنة سحابية،
> مكتبة عامة، رموز مشاركة، وحساب مستخدم.

**المستودع:** <https://github.com/7sn-17/bitaqati>

**التوثيق:** [البنية](docs/ARCHITECTURE.md) · [الإعداد](docs/CONFIGURATION.md) · [المشاركة](docs/DEEP_LINKS.md)

## ما يفعله التطبيق

### الدراسة

- **تكرار متباعد (FSRS):** كل بطاقة لها جدولتها الخاصة، وتظهر عندما يحين
  موعدها لا قبل ذلك.
- **حدود يومية قابلة للضبط:** عدد البطاقات الجديدة (0–200) والمراجعات
  (20–1000) في الجلسة، من الإعدادات.
- **أربعة أنواع بطاقات:** أساسية، ملء الفراغ، اختيار من متعدد، وإخفاء
  أجزاء الصورة.
- **وسوم حرّة** بدل المواد الثابتة، مع بحث وتصفية في كل الشاشات.
- **إحصاءات:** نسبة الحفظ، خريطة أيام المراجعة، وتوقّع الأسبوع القادم.

### المحتوى

- المجموعات مسطّحة: كل مجموعة تحتوي بطاقاتها مباشرة، دون مجلدات متداخلة.
- محرّر بطاقات كامل: وسائط، تلميحات، ملاحظات، وتثبيت البطاقات المهمة.
- استيراد وتصدير مجموعة كاملة كنسخة مستقلة.

### الحساب والمزامنة

- تسجيل الدخول بحساب Google، أو وضع الزائر للتصفح دون حساب.
- **اسم معروض قابل للتعديل** يتجاوز اسم حساب Google في كل الشاشات، ويبقى
  بعد تسجيل الخروج وإعادة التثبيت.
- **مزامنة ثنائية الاتجاه:** كل تعديل يُحفظ محلياً أولاً ثم يُرفع، وما تغيّر
  على جهاز آخر يُنزَّل عند أول اتصال.

### المجتمع

- **مكتبة عامة** فيها مجموعات منشورة، مع تقييم بالنجوم وعدّاد استخدام.
- **رمز مشاركة من ستة أحرف** لكل مجموعة، يُقرأ هاتفياً ويُكتب بسهولة.
- **نشر وإلغاء نشر** في أي وقت، مع خصوصية `خاص` أو `غير مُدرج` أو `عام`.
- **إسناد دائم:** من ينسخ مجموعة تظهر لديه بوسم «مقتبسة من …»، ويبقى اسم
  المؤلف الأصلي محفوظاً حتى لو حُذفت المجموعة الأصلية.

### الخصوصية والحقوق

- سياسة خصوصية وشروط استخدام داخل التطبيق، من الإعدادات ومن شاشتي الدخول
  والبداية.
- حذف مجموعة يحذف كل ما يتصل بها — البطاقات، حالة الجدولة، سجل المراجعات،
  وطوابير المزامنة — من الجهاز ومن السحابة.
- شاشة المطور فيها وسائل تواصل مباشرة.

## الشاشات

| الشاشة | الوصف |
|---|---|
| البداية | ثلاث صفحات تعريفية عند أول تشغيل |
| الدخول | Google أو وضع الزائر، مع روابط الخصوصية والشروط |
| الرئيسية | تذكير اليوم، بطاقة المراجعة، وآخر المجموعات |
| مجموعاتي | كل المجموعات، بحث وتصفية ووسوم |
| تفاصيل المجموعة | البطاقات، الإحصاءات، الخصوصية، رمز المشاركة |
| المراجعة | جلسة كاملة مع التقييم والملخص |
| المكتبة | مجموعات منشورة، تقييم، إدخال رمز مشاركة |
| تقدّمي | نسبة الحفظ، خريطة الأيام، التوقّع |
| البحث | عبر المجموعات والبطاقات |
| الإعدادات | الاسم، المظهر، الأهداف، المزامنة، عن التطبيق |
| المطور | معلومات التواصل |
| الخصوصية / الشروط | النصوص القانونية |

## التشغيل محلياً

المتطلبات: Flutter stable (3.47.8 أو أحدث)، Java 17، Android SDK.

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run \
  --dart-define=SUPABASE_URL=https://mftghnvtdryxzochquee.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

خطوة `build_runner` ضرورية: ملفات Drift المولّدة (`*.g.dart`) غير مرفوعة إلى
المستودع.

بدون مفاتيح Supabase يعمل التطبيق محلياً بالكامل، ويُعطَّل تسجيل الدخول
والمزامنة والمكتبة.

بناء APK:

```bash
flutter analyze
flutter build apk --release
```

## البنية

```text
lib/
├── app.dart                 # MaterialApp.router + RTL + الثيمات
├── main.dart                # تهيئة SharedPreferences وSupabase
├── core/
│   ├── auth/                # مزوّدو الحساب ووضع الزائر
│   ├── config/              # إعدادات وقت البناء
│   ├── router/              # go_router + StatefulShellRoute
│   ├── theme/               # الألوان والخطوط
│   ├── providers.dart       # حالة عامة
│   └── widgets/             # مكوّنات مشتركة
├── data/
│   ├── local/               # Drift: الجداول، الترحيلات، المزوّدات
│   ├── *_repository.dart    # المحتوى، المكتبة، المشاركة، الملف الشخصي
│   ├── sync_service.dart    # دفع وسحب التغييرات
│   └── *_providers.dart     # مزوّدو Riverpod لكل طبقة
├── domain/                  # النماذج والتعدادات
└── features/                # مجلد لكل منطقة في التطبيق
```

طبقة البيانات السحابية في `supabase/migrations/`. التطبيق لا يحتوي على أي
مفتاح سري.

## الاختبار والبناء الآلي

- `Build Android APK` يشغّل التوليد والتحليل ثم يبني APK عند كل دفعة إلى
  `main`.
- `Release APK` ينشر إصداراً موقّعاً عند كل وسم `v*`.
- `flutter analyze` يفشل على أي ملاحظة، لا على الأخطاء فقط.

## الخصوصية

- لا تُضمّن مفاتيح `service_role` ولا مفاتيح مزوّدي الخدمة في التطبيق أبداً.
- كل جداول المستخدم محمية بـ Row Level Security.
- المكتبة العامة تعرض فقط المجموعات التي اختار مالكها نشرها.
- النصوص الكاملة في [سياسة الخصوصية](lib/features/legal/privacy_policy_screen.dart)
  و[شروط الاستخدام](lib/features/legal/terms_of_service_screen.dart).
